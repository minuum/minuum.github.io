저는 학부 연구생으로 VLA 모델을 모바일 로봇 플랫폼에 탑재하여 자율주행을 수행하는 MoNaVLA 프로젝트를 진행해 왔습니다. VLA 백본(Kosmos-2)의 텍스트 경로 의존성 저하 문제를 per-layer attention 측정과 frozen linear probe(val_acc 96.6%) 분석으로 진단하여, 사후 학습이 다운스트림 미세 조정에 관계없이 텍스트 경로를 훼손했음을 발견하였습니다. 이어 목표 물체 masking 시 행동 예측이 100% 반전되는 ablation 연구를 통해 시각적 접지(visual grounding)가 주행 결정을 주도함을 규명했습니다. 이러한 취약점을 해결하기 위해 PaliGemma2를 zero-shot visual grounder로 활용하여 실시간 위치를 추출하고, 이를 Kosmos-2 비전 인코더, 바운딩 박스 이력, L2 정규화와 결합한 2단계 분해(decomposition) 파이프라인을 설계했습니다. 이를 통해 end-to-end baseline의 실패(성공률 0%에 수렴)를 극복하고 96.6%의 closed-loop 주행 성공률(FPE 0.094m)을 기록하였습니다. 실물 구동을 위해 Serbot 2 플랫폼에 Jetson Orin Linux 환경과 ROS2 드라이버를 직접 구성하고, 제어 지터와 응답 지연 문제를 완화하는 작업을 해보았습니다. 

플랫폼은 지상 모바일 로봇과 비행/다중 로코모션 로봇으로 다르지만, 여러 모달리티의 정보를 결합해 로봇의 인지와 행동으로 연결하는 AMRL의 Multimodal AI 연구 방향은 제가 MoNaVLA에서 시각-언어 정보를 결합해 모바일 로봇의 주행 행동을 결정했던 작업과 같은 문제의식을 공유한다고 생각합니다. 무거운 비전-언어 모델을 임베디드 환경(Jetson Orin)에서 실시간으로 구동하고 물리적 지연을 보정한 경험이 AMRL의 다양한 모빌리티 플랫폼 실험에 보탬이 될 수 있다고 생각합니다.
